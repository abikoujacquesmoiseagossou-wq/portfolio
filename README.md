## Déploiement Vercel — accès public (IMPORTANT)

Si le site affiche une page de protection / login Vercel :

1. Ouvrez le projet sur [vercel.com](https://vercel.com)
2. **Settings → Deployment Protection**
3. Désactivez la protection pour **Production** (mettre **Off** / Disabled)
4. Enregistrez, puis rechargez https://portfolio-jack-4640.vercel.app/

Sans cette étape, le portfolio n’est pas accessible publiquement.
