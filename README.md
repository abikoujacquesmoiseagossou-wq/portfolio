## Rendre le site public (si page Login)

Si Vercel affiche **Deployment Protection** :

1. [vercel.com](https://vercel.com) → projet **portfolio**
2. **Settings → Deployment Protection**
3. Production → **Disabled / Off**
4. Lien direct : https://vercel.com/jack-4640/portfolio/settings/deployment-protection
