# Premiers clients en 30 jours

Ebook freelance personnalisé + templates prêts à l’emploi.

## Ouvrir

- **Ebook complet :** ouvre `index.html` dans ton navigateur
- **Exporter en PDF :** bouton en haut à droite (Imprimer → Enregistrer au format PDF)

## Templates bonus

| Fichier | Usage |
|---------|--------|
| `templates/devis.html` | Proposition commerciale 2 options |
| `templates/script-appel.html` | Script d’appel découverte 15 min |
| `templates/checklist-30-jours.html` | Suivi semaine par semaine |

## Personnaliser

Remplace dans les fichiers :
- `[Ton prénom]` / `[Ton nom / marque]`
- ton offre exacte
- tes prix
- ton email / portfolio / Calendly

## Contenu inclus

1. Offre claire (formule + exemples métiers)
2. Grille de prix 3 niveaux
3. Canaux d’acquisition sans pub
4. **10 templates de messages** (LinkedIn, email, relances, communautés)
5. Script d’appel + gestion d’objections
6. Structure de devis + messages de closing
7. Plan d’action 30 jours + checklists
